# 写作任务单：{任务名}

> 对应 references/methodology.md 第六节。每次写作填写一张，确保文章完成实际任务（文风规则只负责表达方式，不负责内容）。

## 任务单

| 字段 | 内容 |
|---|---|
| 文章目的 | 希望读者理解什么，或完成什么行动 |
| 目标读者 | 读者背景与已有知识 |
| 内容材料 | 可使用的事实、观点、案例及来源 |
| 必须保留 | 核心判断、条件、数据和因果关系 |
| 结构要求 | 已确定的大纲，或允许自由组织的范围 |
| 形式要求 | 平台、体裁、篇幅 |
| 文风版本 | 本次使用的规则包版本（如：{作者}-{体裁} 规则包 V0.1） |
| 参考片段 | 按相关性选择的少量提炼样本片段 |

## 生成流程（固定五步）

1. **检查材料是否充足** → 2. **确定内容结构** → 3. **应用文风** → 4. **检查事实与表达** → 5. **输出**

注意：

- 材料缺口需要明确指出，不能为了满足某条文风规则补出故事。
- 文风规则与任务要求冲突时，按规则包"冲突处理顺序"执行（任务明确要求 > 文风规则）。
